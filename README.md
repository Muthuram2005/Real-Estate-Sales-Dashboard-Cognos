# 🏡 Real Estate Sales Dashboard – IBM Cognos Analytics  

An interactive **Real Estate Sales Dashboard** built using **IBM Cognos Analytics** to analyze Airbnb property performance across major cities. This dashboard helps investors, analysts, and business users understand pricing trends, revenue insights, customer engagement patterns, and location-based performance.

---

## ✨ Key Takeaways

- **Tool:** IBM Cognos Analytics (Dashboard & Reporting)  
- **Data:** Cleaned *Airbnb Real Estate Listings* (~72,000 entries)  
- **Purpose:** Convert raw property data into **actionable BI insights**  
- **Insights:** Reveal market demand, optimal pricing ranges, high-performing cities, and customer review patterns  

---

## 📊 Features & Visualizations

- **Revenue Trends:** Time-based revenue insights across cities  
- **Pricing Analysis:** Distribution of listing prices, average vs. peak pricing  
- **Customer Engagement:** Review counts, ratings, and booking frequency  
- **Location Comparison:** Performance by city using interactive visuals  
- **Top Listings:** Highest revenue & best-rated properties  
- **Multiple Visualization Types:**  
  - Bar charts  
  - Line charts  
  - Pie charts  
  - Scatter plots  
  - Hierarchical tree diagrams  

---

## 🛠️ Built With

- **IBM Cognos Analytics** – Dashboard development  
- **Microsoft Excel** – Data cleaning & preprocessing
